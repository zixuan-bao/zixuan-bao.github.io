This template does not currently load analytics, advertising, or third-party comment scripts. It does not display visitor counts.

Search runs in your browser using a static index of the website. Opening photographs does not send them to a separate service. Stock photographs and the public GitHub avatar are stored with the site.

External links take you to other providers, whose own privacy practices apply. Your hosting provider may process ordinary request logs.

If comments, analytics, or email subscriptions are enabled later, update this page to describe the services actually used.
